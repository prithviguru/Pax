`docs/index.html`; the planner can also set a card's `art` to one of these names).

## Sources

The original sheets these were cut from are in `sources/`. To add more: upload a new sheet with each
item on the plain beige background and its name underneath, then cut it out with
`tools/cutouts.py` (it takes the sheet, an output folder, and the grid of names and rows).
